# Fonts

CMU Sans Serif (Computer Modern Unicode, by Andrey V. Panov), self-hosted for the JIQ 2026 deck so that it matches the Latin Modern Sans of the beamer original.

The WOFF2 files are Latin subsets made with fontTools from the Debian `fonts-cmu` package. They are distributed under the SIL Open Font License 1.1, see `OFL.txt`.
